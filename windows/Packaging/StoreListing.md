## Description

```
The web, just the words.

SimpleWeb Text Browser shows web pages as plain text on a calm, glowing screen styled after a 1980s computer terminal. There are no pictures, videos, sounds, adverts or pop-ups: only the words, the links and simple forms.

It's made for reading. Open a news story, a Wikipedia article or a free book from Project Gutenberg and you get the text, set out in one steady column, with nothing moving around it.

Links are numbered, so you can click one or type its number. Type search words where the address goes to search with DuckDuckGo. Text boxes, buttons, tick boxes and drop-down menus still work, drawn in the same terminal style.

Pages are loaded by Microsoft Edge WebView2, so modern sites work, but images, video, audio and fonts are blocked before they download. Pages load quickly and use very little data.

Choose green, amber or white phosphor, turn the screen glow on or off, and go full screen for distraction-free reading.

No accounts, tracking, analytics or adverts. SimpleWeb Text Browser connects only to the websites you visit.

Made by Awkward Snail: calm, simple apps that stay the way you left them. One low price, no subscriptions or in-app purchases. The source code is free on GitHub.
```

## Notes for certification (in *Submission options*)

```
SimpleWeb Text Browser is a WPF desktop app packaged as MSIX. runFullTrust is required because it is a classic desktop (WPF) application. Web pages are loaded with Microsoft Edge WebView2 (Chromium), as policy 10.2.1 requires for apps that browse the web; the app then shows only the page's text and links. No account or sign-in is needed to test it: type any address, or search words, in the bar at the top.
```
